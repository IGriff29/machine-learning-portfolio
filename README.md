# Ian Griffith - Machine Learning Portfolio

This repository contains machine-learning coursework projects and self-directed portfolio extensions focused on practical model development, evaluation, AI workflow testing, and monitoring.

## Project Categories

- **Coursework-derived** projects are reorganized from completed Applied Computing machine-learning assignments.
- **Portfolio extension** projects are additional self-directed demonstrations built to reinforce and apply skills from coursework.

## Technical Themes

## Repository Goal

The goal is to show a progression from core supervised-learning coursework into practical ML-engineering tasks such as reproducible preprocessing, prompt evaluation, logging, drift detection, experiment tracking, and research documentation.

## Academic Integrity Note

Coursework-derived folders reflect completed class assignments that were reorganized for portfolio presentation. Portfolio-extension folders are clearly labeled as self-directed demonstrations and are not presented as graded course assignments.
