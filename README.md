# Ian Griffith — Machine Learning Project Portfolio

A curated set of machine-learning projects developed through Applied Computing coursework and prepared as standalone GitHub repositories.

## Recommended repositories

### 1. COMPAS Classification: Model Comparison and Ensembles
**Best overall ML portfolio project.** Demonstrates preprocessing, model tuning, multiple classification algorithms, bagging, Random Forest, voting ensembles, baselines, and 10-fold cross-validation.

### 2. Ozone Level Classification with Decision Trees
Strong focused classification project demonstrating ROC/AUC, out-of-fold predictions, decision trees, hyperparameter tuning, and visualization.

### 3. Bike Sharing Regression with Decision Trees
A complementary regression project demonstrating RMSE, R-squared, cross-validation, and model tuning.
