# Ian Griffith - Machine Learning Portfolio

This repository showcases machine-learning coursework and self-directed portfolio projects focused on practical model development, evaluation, AI workflow testing, reproducibility, and monitoring.

## Featured Projects

- **[COMPAS Ensemble Classification](compas-ensemble-classification/)** — Ensemble learning with Decision Trees, KNN, Naive Bayes, Logistic Regression, Random Forest, Bagging, Voting, and cross-validation.
- **[LLM Prompt Evaluation Framework](llm-prompt-evaluation/)** — Prompt engineering, prompt versioning, evaluation rubrics, structured testing, CSV reporting, and LLM quality analysis.
- **[Model Monitoring & Drift Detection Demo](model-monitoring-demo/)** — Model monitoring, data drift, Population Stability Index (PSI), logging, threshold-based alerts, and operational reporting.
- **[Neural Network Classification Demo](neural-network-classification-demo/)** — TensorFlow/Keras, neural networks, standardization, early stopping, binary classification, and model evaluation.
- **[Ozone Level Classification](ozone-level-classification/)** — Decision Tree classification, ROC/AUC analysis, GridSearchCV, and cross-validation.

## Project Categories

- **Coursework-derived** projects are reorganized from completed Applied Computing machine-learning assignments.
- **Portfolio extension** projects are additional self-directed demonstrations built to reinforce and apply skills from coursework.

The goal of this repository is to demonstrate progression from foundational supervised-learning coursework into practical machine-learning engineering workflows involving preprocessing, model evaluation, prompt testing, logging, drift detection, experiment tracking, model monitoring, and technical research.

## Academic Integrity Note

Coursework-derived folders reflect completed class assignments that were reorganized for portfolio presentation.
