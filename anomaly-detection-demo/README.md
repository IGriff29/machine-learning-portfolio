# Anomaly Detection Demo

Uses Isolation Forest to identify unusual observations and summarize anomaly scores in synthetic monitoring data.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- Isolation Forest
- Anomaly detection
- Synthetic monitoring data
- Outlier scoring
- Operational ML

## Run
```bash
pip install -r requirements.txt
python src/anomaly_detection_demo.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
