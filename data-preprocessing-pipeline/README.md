# Reusable Data Preprocessing Pipeline

Reproducible preprocessing workflow for mixed numeric and categorical data using scikit-learn pipelines.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- Missing-value handling
- One-hot encoding
- Standardization
- ColumnTransformer
- Train/test splitting
- Pipeline design

## Run
```bash
pip install -r requirements.txt
python src/data_preprocessing_pipeline.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
