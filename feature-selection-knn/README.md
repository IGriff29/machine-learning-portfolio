# Feature Selection with K-Nearest Neighbors

Compares KNN performance before and after univariate feature selection on a standard classification dataset.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- KNN
- Feature selection
- StandardScaler
- SelectKBest
- Cross-validation
- Accuracy comparison

## Run
```bash
pip install -r requirements.txt
python src/feature_selection_knn.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
