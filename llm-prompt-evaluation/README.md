# LLM Prompt Evaluation Framework

Versions prompts, evaluates sample responses against a transparent rubric, and writes a comparison report without requiring a paid API.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- Prompt engineering
- Prompt versioning
- Evaluation rubrics
- Structured testing
- CSV reporting
- LLM quality analysis

## Run
```bash
pip install -r requirements.txt
python src/llm_prompt_evaluation.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
