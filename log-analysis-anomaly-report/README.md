# System Log Analysis & Anomaly Report

Parses sample application logs, aggregates severity counts, and surfaces repeated error patterns for operational review.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- Log parsing
- Monitoring
- Error aggregation
- Operational reporting
- Python standard library

## Run
```bash
pip install -r requirements.txt
python src/log_analysis_anomaly_report.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
