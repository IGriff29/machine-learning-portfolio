# Lightweight ML Experiment Tracker

Runs a small hyperparameter experiment and stores model settings and evaluation metrics in a CSV results log.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- Experiment tracking
- Hyperparameter testing
- CSV logging
- Random Forest
- Reproducibility

## Run
```bash
pip install -r requirements.txt
python src/ml_experiment_tracker.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
