# ML Research Review Template

A structured workflow for documenting machine-learning papers, claims, datasets, metrics, limitations, and reproducibility notes.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- Technical research
- Literature review
- Evidence tracking
- Reproducibility
- Research communication

## Run
```bash
pip install -r requirements.txt
python src/ml_research_review_template.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
