# Classification Model Benchmark

Benchmarks several common classifiers under the same cross-validation protocol and ranks them by mean accuracy.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- Decision Tree
- Logistic Regression
- KNN
- Random Forest
- Naive Bayes
- Cross-validation
- Model comparison

## Run
```bash
pip install -r requirements.txt
python src/model_comparison_benchmark.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
