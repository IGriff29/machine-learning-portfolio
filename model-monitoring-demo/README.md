# Model Monitoring & Drift Detection Demo

Simulates production model monitoring by comparing baseline and current feature distributions and flagging drift.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- Model monitoring
- Data drift
- PSI
- Logging
- Threshold-based alerts
- Operational reporting

## Run
```bash
pip install -r requirements.txt
python src/model_monitoring_demo.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
