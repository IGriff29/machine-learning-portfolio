# Naive Bayes Text Classification

Builds a compact text-classification pipeline using TF-IDF features and Multinomial Naive Bayes.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- Text preprocessing
- TF-IDF
- Multinomial Naive Bayes
- Pipeline
- Classification report

## Run
```bash
pip install -r requirements.txt
python src/naive_bayes_text_classification.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
