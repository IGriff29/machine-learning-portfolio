# Neural Network Classification Demo

Demonstrates a small Keras binary-classification workflow with standardized inputs, validation data, and early stopping.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- TensorFlow/Keras
- Neural networks
- StandardScaler
- Early stopping
- Binary classification
- Model evaluation

## Run
```bash
pip install -r requirements.txt
python src/neural_network_classification_demo.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
