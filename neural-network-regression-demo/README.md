# Neural Network Regression Demo

Demonstrates Keras regression with standardized features, early stopping, and RMSE evaluation.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- TensorFlow/Keras
- Regression
- StandardScaler
- Early stopping
- RMSE
- Deep learning workflow

## Run
```bash
pip install -r requirements.txt
python src/neural_network_regression_demo.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
