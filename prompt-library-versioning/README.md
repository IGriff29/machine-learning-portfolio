# Prompt Library & Version Control Demo

Maintains reusable prompt templates with metadata and demonstrates a simple version-selection workflow.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- Prompt libraries
- Version control concepts
- Metadata
- Template management
- Reproducible AI workflows

## Run
```bash
pip install -r requirements.txt
python src/prompt_library_versioning.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
