# Random Forest Feature Importance

Trains a random forest and reports the most influential input features for a classification task.

## Project Type
Self-directed portfolio extension created to reinforce machine-learning and AI engineering concepts studied in Applied Computing coursework.

## Skills Demonstrated
- Random Forest
- Feature importance
- Train/test evaluation
- Interpretability
- pandas

## Run
```bash
pip install -r requirements.txt
python src/random_forest_feature_importance.py
```

## Notes
This project is designed as a compact, reproducible demonstration rather than a production deployment.
